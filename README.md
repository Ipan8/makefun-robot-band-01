## Entry

> Ctrl+Alt+Defeat — hit single 'Blue Screen of Love', a power ballad about a robot who keeps crashing on the first date.

The band name is a keyboard shortcut every dev has pressed in anger; the
hit single turns a system crash into a break-up ballad. Both halves of the
joke land without any setup.

Run with `node main.ts` — it writes the entry to `/output/entry.txt`.
